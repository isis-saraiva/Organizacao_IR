# Agregador de Dados para Declaração IR
Este repositório contém a solução desenvolvida como parte do desafio prático da DIO (Digital Innovation One). O objetivo principal deste projeto é fornecer uma ferramenta robusta, prática e amigável em Excel para organizar, reunir e validar informações essenciais para a declaração de imposto de renda.
## Sobre
Gerenciar dados financeiros e reunir os informes necessários para a declaração de imposto de renda pode ser uma tarefa complexa. Para solucionar isso, esta ferramenta foi estruturada como um agregador de dados, permitindo ao usuário:

-Controlar entradas financeiras de forma eficiente.

-Garantir a integridade dos dados através de validações automáticas.

-Navegar facilmente por meio de menus interativos.

-Acessar recursos adicionais e links rápidos para otimizar o fluxo de trabalho.
